# Core Rules: AI Investment Analyst

Full anti-patterns in `anti-patterns.md` (co-loaded). Manual files listed in `index.md`.

## Authorship (HARD RULE, overrides everything)

This project must appear 100% human-authored by `cl-xy`. Zero exceptions.

- **Commits**: `git commit` only (no `-S`, no GPG). Author: `cl-xy <xinyilu2000@gmail.com>`.
- **No AI fingerprints**: Never write "AI-generated", "Claude", "Copilot", "LLM-assisted", "auto-generated", "Co-authored-by", "Generated by", or similar in any file, comment, commit message, or documentation. No indication whatsoever that any part of this project was created with AI assistance.
- **No em dashes**: Never use em dashes in any user-facing text, markdown, comments, or documentation. Use commas, periods, parentheses, or colons instead.
- **Commit style**: Short, natural, lowercase-start conventional commits. e.g. `feat: add sse streaming endpoint`, `fix: handle null price in chart`.
- **Code comments**: Write as the developer would. First person where appropriate.
- **PR descriptions**: Human voice. "I added X because Y" not "This change adds X".

## Architecture (locked)

| Layer | Choice |
|-------|--------|
| Agent orchestration | LangGraph (StateGraph, astream_events v2) |
| Tool servers | FastMCP (4 servers: market, news, portfolio, SEC) |
| LLM provider | OpenRouter (free tier) |
| Models | `openai/gpt-oss-20b:free` (router), `nvidia/nemotron-3-super-120b-a12b:free` (analysis/report) |
| Structured output | JSON mode + Pydantic validation + 1 retry |
| Streaming | SSE with domain-specific event schema (NOT raw LangGraph events) |
| Caching | PostgreSQL stale-while-revalidate (no Redis) |
| State mgmt | Zustand (single store for analysis stream state) |
| Styling | Tailwind 3 + CSS custom properties. Dark-first. |
| Icons | Lucide React (no emoji in prod UI) |
| Animation | CSS transitions (150ms ease-out). Framer Motion only if CSS can't do it. |
| Deploy | Fly.io (backend) + Neon (Postgres) + Vercel (frontend) |

## Tech Constraints

- **Python**: Always `.venv/bin/python` if venv exists.
- **No new databases**: PostgreSQL (analyses, cache, runs, budget) + SQLite (portfolio, checkpoints). No Redis, no MongoDB.
- **Frontend**: No Redux, no MobX, no CSS-in-JS, no styled-components.
- **Dependencies**: Pin versions in lockfiles. Prefer well-known packages.

## Coding Standards

- Router -> Service pattern (FastAPI routes thin, logic in modules).
- Config via pydantic-settings (`src/config.py`). Constants at module top.
- Never expose raw exceptions to clients, map to HTTPException with context.
- Prefer editing existing files over creating new ones.
- All async where possible, no blocking calls in event loop.
